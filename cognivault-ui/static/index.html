    Индекс и поиск
    Состояние индекса загружается…
    Поиск не работает: индекс заблокирован. В базе осталась коллекция от предыдущей версии сервиса — её формат этот релиз не читает. Поиск и индексация отвечают ошибкой, новые документы не индексируются. Лечится только пересозданием коллекции — кнопка ниже. Старый индекс при этом удаляется безвозвратно, а новый собирается из файлов вольта: файлы не пострадают.

    Переиндексация заново разбирает и векторизует ваши документы. Сами файлы не меняются. Задача выполняется на сервере: страницу можно закрыть, прогресс не потеряется.
    Оценка качества ответов Прогоняет выбранный набор вопросов через чат и считает метрики. Идёт под вашим токеном и вашими настройками — значит меряет именно вашу конфигурацию. На каждый вопрос приходится несколько обращений к модели, поэтому полный прогон может идти долго. Абсолютным числам судьи верить нельзя — осмысленна только разница между двумя прогонами.
    Можно загрузить JSONL или Excel (.xlsx).
    Попадает в имя отчёта. Латиница, цифры, точка, дефис, подчёркивание.
    0 — весь выбранный набор. Начните с 5, чтобы проверить, что судья отвечает.

    Пересоздание нужно, когда изменилась схема индекса: коллекция удаляется и собирается заново для всех пользователей сразу.

    Это удалит векторы ВСЕХ пользователей, а не только ваши. Пока идёт пересоздание, поиск по базе знаний не находит ничего — ни у вас, ни у остальных. Сами документы не удаляются, но операция может занять много времени.

    Коллекция — это единственный существующий индекс, и снимка с него нет: восстановить его после удаления будет нельзя. Уцелеют файлы вольта — весь индекс будет собран из них заново.
